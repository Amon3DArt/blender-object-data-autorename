# Changelog

## 1.0.0

Initial release.

- Auto-rename object-data to match its object's name on F2, Outliner
  double-click, and Ctrl+F2 Batch Rename.
- Multi-user (instanced) data support: renaming one instance updates
  every instance; renaming several instances together uses the active
  object's new name.
- Outliner header toggle to enable/disable the sync without disabling
  the add-on.
- Preferences: per object-type filter (with matching Outliner icons),
  Select All / Deselect All, and an option to skip multi-user data.
